Simple Hello World C++ program.

Build and run (Windows PowerShell):

```powershell
g++ -std=c++17 -O2 -o main.exe .\main.cpp
.\main.exe
```

Build and run (Linux/macOS):

```bash
g++ -std=c++17 -O2 -o main main.cpp
./main
```

Notes:

- Requires a C++ compiler (g++, clang++ or MSVC).
- On Windows you can install MinGW-w64 or use Visual Studio's developer command prompt (adjust commands accordingly).
